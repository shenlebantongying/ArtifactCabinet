# Spinning Lock Pick Game

Replication of <https://liquipedia.net/dota2/Dark_Carnival/Minigames#Pick_The_Lock>.

```sh
odinfmt . -w
odin run .
```

# Notes
- All angle are stored in degree.
- Each Seg angle range is below 30
